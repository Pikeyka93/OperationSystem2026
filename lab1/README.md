## Условие

Родительский процесс создаёт два дочерних процесса. Родительский и дочерние
процессы должны быть представлены разными программами.

Родительский процесс принимает от пользователя строки произвольной длины и
пересылает их в `pipe1`. Процессы `child1` и `child2` производят работу над
строками. `child2` пересылает результат своей работы родительскому процессу.
Родительский процесс полученный результат выводит в стандартный поток вывода.

- `child1` переводит строки в нижний регистр;
- `child2` превращает все пробельные символы в символ `_`.

Схема взаимодействия:

```
user ─► parent ──pipe1──► child1 ──pipe_mid──► child2 ──pipe2──► parent ─► stdout
```

## Структура

| Файл             | Назначение                                                       |
|------------------|------------------------------------------------------------------|
| `src/parent.c`   | родительский процесс: создаёт каналы, `fork()` + `execv()` детей |
| `src/child1.c`   | перевод в нижний регистр (латиница и кириллица UTF-8)            |
| `src/child2.c`   | замена пробельных символов (`' '`, `\t`, `\v`, `\f`, `\r`) на `_` |
| `src/common.h`   | общие функции: `write_all`, вывод ошибок                         |
| `tests/`         | автотесты                                                        |
| `report/`        | отчёт (DOCX и PDF)                                               |

Символ `\n` не заменяется: это разделитель строк, а не часть строки.

## Сборка и запуск

Работает на Linux и macOS. Нужен компилятор C (`gcc` или `clang`) и `make`.

```bash
make          # сборка в build/
make run      # запуск ./build/parent
make test     # автотесты
make clean
```

Программы `child1` и `child2` должны лежать в том же каталоге, что и `parent`.
Ввод строк завершается сочетанием `Ctrl+D` (конец файла).

Пример:

```
$ ./build/parent
Hello World
hello_world
ОПЕРАЦИОННЫЕ   Системы
операционные___системы
^D
```
